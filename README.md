# dotfiles

Hyprland + Waybar + Wofi в спокойном зелёном стиле (Arch Linux).

- прозрачный бар, у каждого модуля свой овал
- таскбар с иконками приложений
- попапы Wi-Fi, Bluetooth и питания
- раскладка клавиатуры, погода, горизонтальная батарея

## Установка

    sudo pacman -S --needed git
    git clone https://github.com/AmirGasymov/dotfiles.git
    cd dotfiles
    ./install.sh

Скрипт ставит пакеты, делает бэкап старых конфигов и копирует новые.
